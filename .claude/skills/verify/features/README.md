# byox feature map

One file per learner-facing feature. Each one says what the feature is, how a learner reaches it, how to drive it, and what end state proves it.

- [lesson-and-verify.md](lesson-and-verify.md). Read a lesson, press Verify, get a step green, then the lesson green with a celebration.
- [hints.md](hints.md). Reveal hints one at a time, gated by the server.
- [solution-lock.md](solution-lock.md). Show solution and Compare stay locked until green or skipped.
- [explain-failure.md](explain-failure.md). The coach explains a red verify without the solution or unrevealed hints.
- [concept-page.md](concept-page.md). Go deep opens a concept page with mermaid diagrams.
